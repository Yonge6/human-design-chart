# AI Growth Coach App Store posters

Four posters per locale and device family, 16 exports total.

- Locales: English (United States) and Simplified Chinese.
- iPhone 6.5-inch exports: 1284 × 2778.
- iPad 13-inch exports: 2064 × 2752.
- Stories: AI growth coach, four-domain reflection, user-controlled life stories, action and review.
- Screens: current Buer Within 1.0 (2) UI rendered with synthetic sample content.
- No real user profile, testimonial or outcome claim appears in the assets.
- Human Design is deliberately not the screenshot story because it is an optional interpretive lens rather than the product's primary experience.

`index.html` is the source layout. Render with `lang`, `device`, and `index` query parameters.
