# 不二说明书完整体验整合

用户反馈：说明书 tab 仍沿用旧版 UI，与首页割裂。沿用已选第 3 版视觉，不另开视觉方向。

实施范围：
- 填写页使用同一深蓝、青色、衬线标题、轨道图片与侧栏；三步进度可见，校验和日期/地点能力保留。
- 结果页以可读的摘要为主；概览、深入解读、人类图三个页签整合内容，历史 H5 图只放在人类图页签中，不改变图的渲染。
- 长篇解读变为内嵌章节；关联问题可以带着当前结果的匿名摘要返回首页输入框，用户点击发送才发请求。

- API 未配置状态保持真实。只更新独立 H5 体验站，原网站不变。
