# Relationship guide v2 — approved design

User approved rebuilding and deploying all six categories on 2026-10-08.

Order: overview (how we relate), communication (hear each other), friction (decide together), rhythm (sustainable rhythm), repair (repair disagreements), practice (grow together). Existing storage keys are preserved; their UI meaning changes only for v2 readings. Older readings stay in a labeled expandable legacy section, never silently regenerated.

Plain-language, immediately readable foundations and calculated-connection prompts precede expandable chart evidence. Every generated category must connect actual records/chart structure to an observable situation and a concrete action. The more detailed overview has five short paragraphs. AI evidence paragraphs are collapsible. No compatibility scores, destiny claims, invented behaviors or gender inference. Account sync does not regenerate readings or broaden AI consent.
